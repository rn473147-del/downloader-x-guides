1. Kenali tiga lapisan yang dapat menampilkan subtitel

Lapisan pertama adalah teks yang tertanam permanen atau burned-in. Hurufnya sudah menjadi bagian dari setiap bingkai gambar sehingga tombol CC tidak dapat menghilangkannya. Lapisan kedua adalah trek subtitel yang tersimpan di dalam wadah video. Pemutar dapat menawarkan bahasa atau nama trek, lalu menyalakan atau mematikannya. Lapisan ketiga adalah file pendamping seperti .srt, .vtt, atau .ass yang dibaca dari folder yang sama.

Subtitel ganda muncul ketika dua dari tiga lapisan itu terlihat sekaligus. Contohnya, video sudah memiliki teks tertanam tetapi pemutar juga menyalakan trek Indonesia. Contoh lain adalah trek internal aktif bersamaan dengan nama-video.id.srt. Ada pula pemutar yang mengingat pilihan subtitel dari sesi sebelumnya, sehingga lapisan kedua muncul lagi saat file dibuka.

Posisi dan gaya memberi petunjuk, bukan keputusan akhir

Dua teks dengan warna, ukuran, atau posisi berbeda sering berasal dari lapisan berbeda. Namun, gaya yang sama belum membuktikan bahwa file hanya memiliki satu trek. Jangan menghapus apa pun berdasarkan tampilan. Matikan lapisan satu per satu dan catat mana yang berubah.

Uji awal: jeda video pada detik yang menampilkan teks. Matikan subtitel melalui menu pemutar. Jika satu baris hilang tetapi baris lain tetap berada di gambar, file kemungkinan memiliki teks tertanam sekaligus lapisan yang dapat dipilih.

2. Simpan rujukan sumber dan lindungi file asli

Catat nama lengkap file, ukuran, durasi, lokasi folder, dan waktu perubahan. Simpan URL sumber, judul, pembuat, serta dasar izin. Gunakan satu salinan kerja jika Anda perlu mengganti nama file pendamping atau memindahkan video. Jangan menguji langsung pada satu-satunya salinan yang dimiliki.

Video ESA di atas memperlihatkan rujukan yang dapat diverifikasi: judul, durasi 23 detik, tanggal publikasi, kredit ESA/Mlabspace, dan keterangan resmi bahwa caption otomatis YouTube tersedia. Mengaktifkan CC pada sematan hanya menunjukkan fitur sumber. Hal itu tidak membuktikan bahwa file lokal Anda memuat trek yang sama atau bahwa proses penyimpanan tertentu akan menyertakan subtitel.

Catatan minimum:
  • nama, ukuran, durasi, dan lokasi file video;
  • detik saat dua teks tampak paling jelas;
  • nama pemutar dan status tombol subtitel;
  • daftar file dengan nama dasar yang mirip di folder yang sama;
  • hasil sebelum dan sesudah satu lapisan dimatikan.
Hak penggunaan: video publik tetap dapat dilindungi hak cipta. Menyimpan file tidak otomatis memberi izin untuk mengubah, menerbitkan ulang, menjual, atau menggunakannya secara komersial. Jangan mencoba melewati akses privat, berbayar, atau pembatasan lain.

3. Jalankan sembilan pemeriksaan secara berurutan

  1. Lindungi file asli. Buat salinan kerja dan jangan mengubah, menghapus, atau mengekspor ulang sumber selama diagnosis.
  2. Pilih satu detik rujukan. Cari adegan yang menampilkan dua baris jelas, jeda, lalu catat waktu dan gaya masing-masing teks.
  3. Matikan subtitel di pemutar. Gunakan menu CC atau Subtitle; perhatikan apakah semua teks hilang, hanya satu lapisan hilang, atau tidak ada perubahan.
  4. Periksa daftar trek. Catat setiap bahasa, label, dan status aktif. Pilih “Off” sebelum mencoba trek satu per satu.
  5. Lihat isi folder. Cari file .srt, .vtt, atau .ass dengan nama dasar yang sama atau hampir sama.
  6. Nonaktifkan pemuatan otomatis untuk satu uji. Jika pemutar memiliki pengaturan tersebut, catat nilai awal lalu matikan sementara.
  7. Buka file yang sama di pemutar kedua. Jangan mengonversi atau mengganti ekstensi; bandingkan detik rujukan yang sama.
  8. Uji salinan di folder kosong. Salin hanya video ke folder baru. Jangan memindahkan file asli atau berkas subtitel pendamping.
  9. Tentukan lapisan yang perlu dipertahankan. Pilih teks tertanam, satu trek internal, atau satu file eksternal sesuai kebutuhan dan kemampuan pemutar.

Ubah satu keadaan setiap kali. Jika Anda sekaligus mengganti pemutar, memindahkan folder, menghapus file SRT, dan mengekspor ulang video, hasil akhir tidak menunjukkan penyebab. Simpan catatan singkat agar setiap perbandingan dapat diulang.

4. Bedakan teks tertanam dari subtitel yang dapat dipilih

Teks tertanam ikut terlihat ketika video dijeda, diputar mundur, atau dibuka pada pemutar apa pun karena ia sudah menjadi piksel gambar. Menu subtitel tidak mengendalikan lapisan tersebut. Jika semua pilihan subtitel sudah “Off” tetapi satu teks masih ada, jangan menganggap tombol gagal; teks itu mungkin memang menyatu dengan video.

Sebaliknya, teks pilihan biasanya berubah atau hilang setelah trek dinonaktifkan. Pemutar dapat memberi latar hitam, mengubah ukuran huruf, atau menempatkan teks lebih rendah daripada teks tertanam. Pengaturan aksesibilitas sistem juga dapat memengaruhi gaya lapisan pilihan tanpa mengubah gambar asli.

Jangan memotong gambar sebagai langkah pertama

Memotong bagian bawah video untuk menghilangkan teks tertanam dapat membuang isi visual dan mengubah rasio. Menutupnya dengan bidang warna juga menghasilkan video baru, bukan memulihkan gambar di balik teks. Jika Anda membutuhkan versi tanpa teks tertanam, pilihan paling aman adalah kembali ke sumber atau proyek asli yang memang tidak memuat lapisan tersebut, selama Anda berhak mengaksesnya.

5. Periksa trek internal, file SRT/VTT, dan pemuatan otomatis

Buka menu trek dan pastikan hanya satu pilihan aktif. Nama seperti “Default”, “Forced”, “English”, atau “Indonesian” dapat berasal dari metadata file. Trek forced kadang menampilkan terjemahan untuk bagian tertentu meski trek lengkap juga aktif. Jangan menghapus trek dari wadah video sebelum Anda membuktikan bahwa duplikasi memang berada di dalam file.

Di folder video, aktifkan tampilan ekstensi nama berkas bila sistem menyembunyikannya. File film.mp4, film.srt, dan film.id.srt dapat dikenali sebagai satu kelompok oleh pemutar. Dua file pendamping dengan bahasa atau nama serupa dapat sama-sama ditawarkan, sedangkan beberapa aplikasi memilih salah satunya secara otomatis.

Untuk pengujian yang dapat dibalik, ganti nama salinan file eksternal, misalnya dari film.id.srt menjadi film.id.srt.nonaktif, atau pindahkan salinannya ke folder uji. Jangan menghapusnya. Buka ulang pemutar dari awal, bukan hanya menekan jeda, karena daftar subtitel mungkin dibaca saat file pertama kali dimuat.

Folder kosong adalah tes pemisahan, bukan perbaikan permanen

Jika hanya video di folder kosong tampil normal, file pendamping atau aturan pemuatan folder ikut berperan. Kembalikan satu berkas subtitel pada satu waktu untuk menemukan pemicu. Jika duplikasi tetap terjadi, fokus pada trek internal, teks tertanam, atau setelan pemutar.

6. Pilih perbaikan paling kecil sesuai bukti

Jika satu lapisan tertanam dan satu trek dapat dipilih, matikan trek pilihan saat menonton. Jika dua trek internal aktif, pilih satu bahasa dan simpan preferensi pemutar hanya bila diperlukan. Jika file eksternal dimuat otomatis, gunakan nama atau folder yang lebih jelas sehingga hanya pendamping yang diinginkan yang cocok dengan video.

Jika masalah hanya muncul pada satu aplikasi, kembalikan setelan subtitel aplikasi tersebut ke keadaan standar atau gunakan pemutar yang membaca file dengan benar. Jangan mengganti ekstensi video; mengubah .webm menjadi .mp4 tidak mengubah trek di dalamnya. Hindari aplikasi penghapus subtitel acak yang meminta unggahan file pribadi atau menjanjikan pemulihan gambar yang tidak pernah tersimpan.

Ekspor ulang hanya masuk akal bila Anda memiliki proyek asli atau izin untuk mengedit dan sudah menentukan lapisan yang benar. Pertahankan file sumber, gunakan nama keluaran baru, lalu bandingkan durasi, gambar, audio, dan detik rujukan sebelum menghapus apa pun. Diagnosis selesai ketika perubahan kecil menghasilkan tampilan konsisten dan dapat diulang.

7. Pertanyaan umum

Mengapa subtitel muncul dua kali padahal saya hanya memilih satu bahasa?

Satu teks mungkin tertanam pada gambar, sedangkan bahasa yang dipilih menambah lapisan kedua. Matikan subtitel pemutar untuk melihat apakah satu baris tetap ada.

Apakah file SRT yang berada di folder sama dapat aktif sendiri?

Ya, beberapa pemutar memuat file pendamping ketika nama dasarnya cocok dengan nama video. Uji salinan video di folder kosong atau nonaktifkan pemuatan otomatis tanpa menghapus file asli.

Bolehkah saya menghapus salah satu file subtitel?

Jangan langsung menghapus. Ganti nama atau pindahkan salinan untuk uji yang dapat dibalik. Setelah penyebab pasti dan cadangan tersedia, Anda dapat menata file sesuai kebutuhan.

Bisakah teks tertanam dimatikan dengan tombol CC?

Tidak. Teks tertanam sudah menjadi bagian dari gambar. Tombol CC hanya mengendalikan trek yang dikenali pemutar sebagai subtitel terpisah.

Apakah video tersemat membuktikan subtitel hasil penyimpanan?

Tidak. Sematan menampilkan sumber YouTube resmi dan fitur caption pada pemutar. Ia tidak menguji file lokal, metode penyimpanan, format, atau trek yang tersedia setelah file dibuat.

8. Jika Anda perlu membedakan teks otomatis dan subtitel kreator

Sesudah lapisan ganda terpisah, periksa asal teks pada halaman sumber. Panduan berikut membantu mengenali label, bahasa, waktu, dan perbedaan antara teks otomatis dengan subtitel yang disediakan kreator.

Catat URL, pembuat, izin, dan pilihan subtitel yang benar-benar tersedia. Simpan file asli, gunakan satu salinan kerja, lalu uji satu lapisan pada satu waktu sebelum mengubah isi.
