คู่มือ YOUTUBE สำหรับมือถือและคอมพิวเตอร์

วิธีคัดลอกลิงก์วิดีโอสาธารณะจาก YouTube

ลิงก์ที่คัดลอกจากปุ่มแชร์ช่วยให้เปิดวิดีโอได้ตรงรายการ ลดความผิดพลาดจากการคัดลอก URL ของหน้าค้นหา เพลย์ลิสต์ หรือโฆษณา คู่มือนี้อธิบายทั้ง Android, iPhone และคอมพิวเตอร์ พร้อมวิธีตรวจสอบโดเมน ความเป็นสาธารณะ และสิทธิ์ก่อนนำลิงก์ไปใช้งาน

คำตอบแบบสั้น

เปิดวิดีโอ YouTube ที่ต้องการ กด แชร์ แล้วเลือก คัดลอกลิงก์ จากนั้นวางลิงก์ในแถบที่อยู่ของแท็บใหม่เพื่อตรวจว่าลิงก์เปิดวิดีโอรายการเดิมและโดเมนเป็น youtube.com หรือ youtu.be ใช้เฉพาะวิดีโอสาธารณะที่คุณเป็นเจ้าของหรือได้รับอนุญาตให้บันทึกและใช้งาน

ตรวจสอบก่อนคัดลอกลิงก์

  • ชื่อวิดีโอ ช่อง และภาพตัวอย่างตรงกับรายการที่ต้องการ
  • วิดีโอเปิดดูได้ตามปกติและไม่ได้เป็นวิดีโอส่วนตัว
  • คุณมีสิทธิ์บันทึก แบ่งปัน หรือใช้ไฟล์ตามวัตถุประสงค์
  • ไม่ได้อยู่บนหน้าค้นหา หน้าแรก หรือหน้าโฆษณาที่อาจให้ URL ผิดรายการ

การมองเห็นวิดีโอไม่ได้หมายความว่าสามารถนำไปเผยแพร่ต่อได้ทุกกรณี ควรตรวจเงื่อนไขของเจ้าของผลงาน ลิขสิทธิ์ และความเป็นส่วนตัวเสมอ

วิธีคัดลอกลิงก์บน Android

  1. เปิดแอป YouTube และเลือกวิดีโอที่ต้องการ
  2. แตะปุ่มแชร์ใต้เครื่องเล่น หากไม่เห็นให้เลื่อนแถวปุ่มเล็กน้อย
  3. เลือกคัดลอกลิงก์ รอข้อความยืนยันว่าคัดลอกแล้ว
  4. เปิด Chrome หรือเบราว์เซอร์อื่น วางลิงก์ในแถบที่อยู่และตรวจผล

ถ้าลิงก์เปิดแอปโดยอัตโนมัติ ให้ตรวจชื่อวิดีโอและช่องในแอปอีกครั้ง ไม่จำเป็นต้องส่งรหัสผ่าน คุกกี้ หรือรหัสยืนยันให้บริการอื่น

วิธีคัดลอกลิงก์บน iPhone และ iPad

  1. เปิดวิดีโอในแอป YouTube หรือ Safari
  2. แตะแชร์แล้วเลือกคัดลอกลิงก์
  3. เปิดแท็บส่วนตัวหรือแท็บใหม่ใน Safari
  4. วาง URL เพื่อตรวจว่าเปิดรายการเดิมและไม่มีข้อความส่วนตัวติดมาด้วย

หากเมนูแชร์ของ iOS แสดงรายชื่อผู้ติดต่อ ให้เลือกคำสั่งคัดลอกแทนการส่งทันที การตรวจลิงก์ก่อนช่วยลดโอกาสส่งวิดีโอผิดรายการ

วิธีคัดลอกลิงก์บนคอมพิวเตอร์

  1. เปิดหน้าวิดีโอที่โดเมน YouTube อย่างเป็นทางการ
  2. กดแชร์ใต้ชื่อวิดีโอและเลือกคัดลอก
  3. หากต้องการอ้างถึงช่วงเวลา ให้เลือกเริ่มที่เวลาปัจจุบันเมื่อเมนูมีตัวเลือกนี้
  4. ทดสอบลิงก์ในแท็บใหม่และเปรียบเทียบชื่อ ช่อง และระยะเวลา

คุณสามารถคัดลอกจากแถบที่อยู่ได้ แต่ปุ่มแชร์มักให้ URL ที่สะอาดกว่าและลดพารามิเตอร์ติดตามที่ไม่จำเป็น

แยกลิงก์วิดีโอ Shorts และเพลย์ลิสต์

ลิงก์วิดีโอทั่วไปมักมีเส้นทาง /watch และรหัสวิดีโอ ส่วน Shorts มักมี /shorts/ ลิงก์เพลย์ลิสต์อาจมีพารามิเตอร์ list= เพิ่มเข้ามา หากต้องการวิดีโอรายการเดียว ให้เปิดวิดีโอนั้นก่อนแล้วใช้ปุ่มแชร์ของวิดีโอ ไม่ควรคัดลอก URL ของหน้ารวมโดยไม่ตรวจสอบ

วิธีตรวจลิงก์อย่างปลอดภัย

  1. อ่านชื่อโดเมนจากซ้ายไปขวาและระวังตัวสะกดเลียนแบบ
  2. เปิดในแท็บใหม่ก่อนวางในเครื่องมือดาวน์โหลด
  3. ตรวจว่าไม่มีข้อมูลบัญชี อีเมล หรือโทเคนใน URL
  4. เก็บ URL ต้นทางและบันทึกสิทธิ์ไว้กับไฟล์เมื่อใช้ในงานหรือการศึกษา

เครื่องมือที่ใช้กับลิงก์สาธารณะไม่ควรถามหารหัสผ่านหรือรหัสยืนยันบัญชี หากพบคำขอดังกล่าวให้หยุดและกลับไปตรวจโดเมน

แก้ปัญหาเมื่อคัดลอกไม่ได้

ไม่พบปุ่มแชร์

แตะเครื่องเล่นหนึ่งครั้ง เลื่อนแถวคำสั่ง หรือเปิดวิดีโอจากหน้ารายการของตนเอง เบราว์เซอร์บางขนาดซ่อนคำสั่งไว้ในเมนูเพิ่มเติม

ลิงก์เปิดวิดีโอคนละรายการ

กลับไปที่หน้าวิดีโอต้นทางและคัดลอกจากปุ่มแชร์ใหม่ ลบลิงก์เก่าออกจากคลิปบอร์ดก่อนทดสอบ

วิดีโอเปิดไม่ได้

ตรวจว่าวิดีโอถูกลบ เปลี่ยนเป็นส่วนตัว จำกัดภูมิภาค หรือจำกัดอายุหรือไม่ อย่าพยายามหลีกเลี่ยงข้อจำกัดการเข้าถึง

คำถามที่พบบ่อย

คัดลอกลิงก์ Shorts ได้หรือไม่?

ได้ เมื่อ Shorts นั้นเป็นสาธารณะและคุณมีสิทธิ์ใช้งาน ให้ใช้ปุ่มแชร์ของรายการนั้นโดยตรง

ต้องเข้าสู่ระบบเพื่อคัดลอกลิงก์หรือไม่?

วิดีโอสาธารณะส่วนใหญ่คัดลอกลิงก์ได้โดยไม่ต้องส่งข้อมูลบัญชีให้เว็บไซต์อื่น

ลิงก์ youtu.be ปลอดภัยหรือไม่?

เป็นโดเมนลิงก์แบบย่อของ YouTube แต่ควรเปิดทดสอบและตรวจปลายทางก่อนใช้งาน

ทำไมลิงก์มีตัวเลขเวลาเพิ่มมา?

คุณอาจเลือกเริ่มที่เวลาปัจจุบัน ลบพารามิเตอร์เวลาเมื่อไม่ต้องการระบุช่วงเริ่มต้น

ใช้ลิงก์เพลย์ลิสต์แทนวิดีโอได้ไหม?

หากต้องการเพียงรายการเดียว ควรเปิดวิดีโอแล้วคัดลอกลิงก์ของวิดีโอนั้นเพื่อลดความสับสน

วิดีโอส่วนตัวใช้ได้หรือไม่?

ไม่ควรพยายามข้ามสิทธิ์หรือข้อจำกัด ใช้เฉพาะเนื้อหาที่เข้าถึงได้อย่างถูกต้องและได้รับอนุญาต
