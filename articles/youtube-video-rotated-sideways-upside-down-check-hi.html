1. “वीडियो घूम गया” को चार अलग समस्याओं में बाँटें

पहला मामला केवल screen orientation का है: फोन घुमाने पर पूरी app या controls बदलते हैं, लेकिन video frame अपनी सही दिशा में रहता है। दूसरा मामला player का है: एक app video की rotation information पढ़ती है और दूसरी app उसे अनदेखा करती है। तीसरा मामला preview का है, जहाँ gallery का thumbnail गलत दिशा दिखाता है पर playback सही रहता है। चौथे मामले में file के frames या export सच में गलत दिशा में होते हैं और लगभग हर player वही परिणाम दिखाता है।

इन स्थितियों का समाधान अलग है। Auto-rotate चालू करना गलत metadata को नहीं बदलता, और video editor में घुमाना केवल पुराने thumbnail को refresh करने का सबसे अच्छा पहला कदम नहीं है। इसलिए पहले यह लिखें कि गलती thumbnail, playback, full-screen, share की हुई copy या केवल एक app में कहाँ दिखाई देती है।

महत्वपूर्ण अंतर: स्क्रीन को घुमाना और video frames को घुमाना एक ही काम नहीं है। Screen lock केवल देखने का तरीका बदलता है; वह local file के pixels या container metadata को ठीक नहीं करता।

2. मूल YouTube वीडियो को orientation का baseline बनाएँ

मूल video page खोलकर title, channel और URL मिलाएँ। शुरुआत, मध्य और अंत से तीन स्थिर दृश्य चुनें। देखें कि source portrait है, landscape है या किसी दृश्य में creator ने जानबूझकर camera घुमाया है। फोन को मेज पर एक तय दिशा में रखें और screen rotation lock का वर्तमान state नोट करें, ताकि हर परीक्षण एक ही परिस्थिति में हो।

Baseline में दर्ज करें:
  • मूल URL, title और channel
  • Source portrait या landscape
  • तुलना किए गए तीन time points
  • Local filename, extension, size और duration
  • पहले player और device का नाम
  • गलती thumbnail में है, playback में है या दोनों में

3. नौ चरणों में rotated local video की जाँच करें

  1. Untouched original सुरक्षित रखें। एकमात्र copy को rotate, trim, rename, convert या overwrite न करें। प्रयोग के लिए अलग working copy बनाएँ ताकि हर परिणाम की तुलना मूल से हो सके।
  2. सही source और सही file मिलाएँ। Thumbnail पर निर्भर न रहें। Title, दृश्य, duration और शुरुआत-मध्य-अंत के frames देखकर सुनिश्चित करें कि आप पुरानी या edited copy नहीं जाँच रहे।
  3. Screen rotation अलग जाँचें। पहले फोन को एक दिशा में रखकर auto-rotate बंद करें और video चलाएँ। फिर केवल screen setting बदलें। यदि controls और पूरी app घूमते हैं लेकिन frame की गलती वही रहती है, तो समस्या केवल screen lock नहीं है।
  4. Full-screen और inline playback की तुलना करें। उसी player में पहले सामान्य view और फिर full-screen खोलें। केवल full-screen में दिशा बदलती हो तो app layout या orientation handling को note करें; file को तुरंत edit न करें।
  5. दूसरे भरोसेमंद player में वही original खोलें। File बदले बिना वही तीन time points चलाएँ। एक player सही और दूसरा गलत दिखाए तो metadata interpretation या player support की दिशा मजबूत होती है।
  6. Gallery thumbnail और playback अलग देखें। Preview टेढ़ा हो लेकिन video चलने पर सही हो तो cache या thumbnail generation संभावित है। File manager से वही file खोलकर पुष्टि करें कि gallery कोई दूसरी copy नहीं दिखा रही।
  7. Width, height और rotation detail पढ़ें। System info या player details में dimensions तथा rotation field दिखें तो ठीक-ठीक दर्ज करें। Field न मिले तो संख्या या metadata की कहानी न गढ़ें।
  8. Transferred copy की तुलना करें। Messaging app, cloud sync या editor से आई copy का size, duration और orientation original से मिलाएँ। Service ने नई file बनाई हो तो उसे original result न मानें।
  9. सबूत के अनुसार अगला कदम चुनें। केवल player गलत हो तो app सहायता या दूसरा compatible player देखें। हर player में गलत हो तो working copy पर non-destructive rotate/export आजमाएँ और output को नए नाम से रखें।

5. फोन, gallery, cloud और editor के व्यवहार को अलग रखें

Android या iPhone पर

Photos या Gallery app कभी imported media का thumbnail पहले बनाती है और बाद में file बदलने पर पुराना preview कुछ समय दिखा सकती है। App बंद करके दोबारा खोलना, सही album देखना और file manager से वही path खोलना कम जोखिम वाले checks हैं। Cache साफ करने या app data हटाने से पहले समझें कि उससे local settings या offline items प्रभावित हो सकते हैं; diagnosis के लिए यह पहला कदम नहीं है।

Video editor में

Editor canvas, preview और exported frame तीन अलग स्तर हो सकते हैं। यदि correction जरूरी हो, working copy import करें, canvas orientation चुनें, केवल आवश्यक 90°, 180° या 270° rotation लगाएँ और छोटा sample export करें। Sample को editor के बाहर दो players में देखें। सही होने पर ही पूरा export करें। बार-बार rotate करने से 90° correction 180° गलती बन सकती है।

6. सुरक्षित सुधार चुनें और जल्दबाज़ी वाले उपायों से बचें

Player-specific समस्या में file न बदलें

यदि वही original दूसरे भरोसेमंद player में सही चलता है, तो पहले player की update, orientation setting या supported format जानकारी देखें। ऐसी स्थिति में conversion नई compression और quality change जोड़ सकता है, जबकि मूल file उपयोग योग्य हो सकती है। जरूरत हो तो सही चलने वाले player का उपयोग करें और test notes रखें।

हर जगह गलत हो तो working copy पर rotate करें

Source सही है लेकिन untouched local file हर tested player में गलत दिखती है, तो अधिकृत content की working copy पर editor से rotation किया जा सकता है। Output को नया नाम दें, पूरा video देखें और शुरुआत-मध्य-अंत मिलाएँ। केवल thumbnail सीधा दिखने पर काम पूरा न मानें। Export के बाद audio, duration और frame crop भी जाँचें, क्योंकि canvas बदलने से किनारे कट सकते हैं या खाली bars जुड़ सकते हैं।

Extension बदलना orientation fix नहीं है

Filename के अंत में .mp4 या दूसरा suffix लिखने से frames नहीं घूमते और metadata विश्वसनीय रूप से नहीं बदलती। इसी तरह file को बार-बार download करना diagnosis नहीं है, जब तक source URL, चुना गया वास्तविक option और हर copy का filename दर्ज न हो। पहले एक result जाँचें; फिर केवल स्पष्ट कारण होने पर नया authorized option चुनें।

उपयोग का अधिकार अलग विषय है। Public YouTube page दिखना download, editing या redistribution की स्वतः अनुमति नहीं देता। निजी, members-only, भुगतान-आधारित या restricted content की पहुँच को पार करने की कोशिश न करें। Creator की अनुमति और लागू नियमों का सम्मान करें।

7. अक्सर पूछे गए सवाल

क्या auto-rotate चालू करने से file स्थायी रूप से सीधी हो जाएगी?

नहीं। Auto-rotate स्क्रीन और app layout को बदलता है। वह encoded frames या video container में दर्ज orientation को स्थायी रूप से नहीं बदलता।

एक player में video सही और दूसरे में 90° घूमा क्यों दिखता है?

Players display metadata या format details को अलग तरह से पढ़ सकते हैं। वही untouched file और वही time points तुलना करें; केवल गलत player की setting या support देखें।

Thumbnail उल्टा है लेकिन playback सही है—क्या file खराब है?

जरूरी नहीं। Gallery का cached thumbnail या preview गलत हो सकता है। File manager से सही path की file खोलें और दो players में actual playback जाँचें।

क्या rotate करके export करने से quality हमेशा समान रहेगी?

गारंटी नहीं। Editor और export settings नई compression, crop या dimensions ला सकती हैं। पहले छोटी working copy पर test करें, untouched original रखें और final output पूरा देखें।

क्या ऊपर का NASA embed Downloader-X के परिणाम की दिशा साबित करता है?

नहीं। Embed मूल YouTube source, title और creator दिखाता है। वह local download, file metadata, resolution, orientation या tool success का परीक्षण नहीं है।

8. Duration भी 00:00 दिखे तो उसे अलग समस्या मानें

Rotation और गलत duration एक साथ दिखाई दे सकते हैं, खासकर gallery या transferred copy में, लेकिन उनका कारण एक होना जरूरी नहीं। File completeness, index और playback को अलग क्रम में जाँचने के लिए संबंधित हिंदी गाइड पढ़ें।

सहेजे गए YouTube वीडियो की अवधि 00:00 दिखे तो क्या जाँचें?

अधिकृत public link से source और local file मिलाएँ

पहले सही YouTube page, orientation और तीन reference frames लिखें। फिर tool में केवल वास्तविक उपलब्ध विकल्प देखें, download पूरा होने दें और untouched file को दो players में जाँचें।
